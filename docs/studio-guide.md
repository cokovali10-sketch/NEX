# Studio Guide

NEX Studio is a visual IDE for NEX development. Currently available in two versions:

## nex-studio (Native UI)
- Built with Dear ImGui
- Basic code editing and syntax highlighting
- Project management
- Build/run buttons

## nex-studio-egui (Egui-based)
- Modern UI with egui
- More features planned
- Currently in development

## Usage
```bash
# Run the native version
nex studio

# Run the egui version
nex-studio-egui
```

## Planned Features
- Real-time error highlighting
- Autocompletion
- Debugging interface
- Visual project structure
